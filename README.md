# Project Description
A web-based system that allows students to book consultation appointments with lecturers and enables lecturers to manage consultation schedules and booking requests.

# Project Objectives

To provide a centralized platform for students to book consultation appointments with lecturers.

To help lecturers manage their consultation schedules and booking requests efficiently.

To prevent double booking of consultation slots.

To improve communication and appointment management between students and lecturers.

# Main Features

- Student and lecturer login
- View available consultation slots
- Request consultation appointments
- View and cancel consultation requests
- Create and manage consultation slots
- Approve or reject booking requests
- Track consultation status (Pending, Approved, Rejected and Completed)
- Prevent double booking
- Support Face-to-Face and Online consultations
- Consultation reminders and notifications
- Calendar View
